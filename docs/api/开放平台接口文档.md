# 开放平台接口文档

本文档描述了 `Medlink` 中定义的开放平台（OpenAPI）接口。

## 根路径

所有接口的根路径为 `/open-api/v1`。

---

## 接口详情

### 1. 测试接口

- **路径:** `/test`
- **方法:** `GET`
- **摘要:** 测试接口，用于验证用户认证和数据权限。
- **认证:** 需要认证 (`@Authorize`)。
- **描述:**
  此接口返回当前认证用户的权限信息。成功时，它会提供一个包含用户维度（如部门、角色等）的列表，可用于了解当前用户的数据访问范围。

- **成功响应示例 (`200 OK`):**

  ```json
  {
    "success": true,
    "dataPermissions": [
      {
        "type": "org",
        "id": "de17dfb5c8054a3e9a4a49a73b941903",
        "name": "测试部"
      }
    ]
  }
  ```

- **失败响应示例 (未认证):**

  ```json
  {
    "error": "No authentication found"
  }
  ```

### 2. 根据科室查询设备

- **路径:** `/devices-by-departments`
- **方法:** `POST`
- **摘要:** 根据科室ID查询权限下的设备。
- **认证:** 需要认证 (`@Authorize`)。
- **描述:**
  - 此接口用于根据一个或多个科室ID查询关联的设备列表。
  - 如果请求体中的 `departmentIds` 列表为空或未提供，接口将返回当前用户权限范围内的所有设备。
  - 返回的每个设备信息中都会包含其所属的科室列表。

- **请求体 (`DepartmentRequest`):**

  ```json
  {
    "departmentIds": ["de17dfb5c8054a3e9a4a49a73b941903"]
  }
  ```

  - `departmentIds` (Array[String], 可选): 科室ID列表。

- **成功响应示例 (`200 OK`):**
  返回一个 `SimpleDeviceDto` 对象数组。

  ```json
  [
    {
      "id": "device123",
      "name": "温度传感器",
      "productId": "product456",
      "productName": "标准温感设备",
      "state": {
        "value": "online",
        "text": "在线"
      },
      "createTime": 1678886400000,
      "departments": [
        {
          "id": "de17dfb5c8054a3e9a4a49a73b941903",
          "name": "心内科"
        }
      ]
    }
  ]
  ```

---

## 数据模型

### DepartmentRequest

| 字段            | 类型          | 描述         |
| --------------- | ------------- | ------------ |
| `departmentIds` | `Array[String]` | 科室ID列表。 |

### SimpleDeviceDto

| 字段          | 类型                  | 描述               |
| ------------- | --------------------- | ------------------ |
| `id`          | `String`              | 设备ID。           |
| `name`        | `String`              | 设备名称。         |
| `productId`   | `String`              | 产品ID。           |
| `productName` | `String`              | 产品名称。         |
| `state`       | `Object`              | 设备状态。         |
| `createTime`  | `Long`                | 创建时间戳。       |
| `departments` | `Array[DepartmentInfo]` | 设备关联的科室列表。 |

### DepartmentInfo

| 字段   | 类型     | 描述     |
| ------ | -------- | -------- |
| `id`   | `String` | 科室ID。 |
| `name` | `String` | 科室名称。 |
